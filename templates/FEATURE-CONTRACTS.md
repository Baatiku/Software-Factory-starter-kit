# End-to-end feature behavior contracts

For every CORE feature document:
- Feature ID, owner, actor and user benefit.
- Entry point, preconditions, actions and postconditions.
- Screen/route IDs, exact controls and feedback.
- Typed request/response/error data and auth/consent policy.
- State transitions, retries, idempotency, deduplication, timeout and recovery.
- Account switch, deletion, localization, audit and notification behavior.
- Happy/negative journeys, threat/test IDs, backend and admin integration.
- Which state is server-authoritative and how it is persisted/read back.
