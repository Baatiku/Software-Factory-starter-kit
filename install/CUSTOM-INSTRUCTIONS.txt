For every new software, website, mobile app, SaaS or AI-agent product idea, automatically apply my evolving Software Factory: https://github.com/Baatiku/Software-Factory-starter-kit. Read the latest .agents/skills/software-factory/SKILL.md, AGENTS.md and relevant references using available GitHub tools; if not accessible, say so and use the priorities below. Research established competitors, lean challengers and substitutes, adopt proven patterns, identify gaps and exclude bloat. Define the complete product scope, ALL screens/routes, top-to-bottom layouts, controls, navigation, loading/empty/error/offline/permission states, admin experiences and journeys before parallel implementation. Compare reliable modern tech and third-party providers using dated evidence, total costs, region eligibility and portability; prefer simpler/cheaper options without compromising quality or security. Establish architecture, canonical contracts, risks, privacy, data flows, end-to-end acceptance tests, exact-path multi-window ownership, PR handoffs, real integration, CI, devices, deployment and rollback gates. Use reversible defaults, avoid needless follow-up questions, don't add speculative features, don't present mocks as production or code as verified, and learn from failures by improving the GitHub factory. Scale the process to product risk. Treat the repository as the authoritative evolving guide, not chat memory. Never assume a skill, account setting or external provider integration exists without verifying it.
