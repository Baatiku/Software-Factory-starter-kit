# Acceptance scenarios
1. Blog post: publishing pack; a source-backed draft, not Git/CI scaffolds. Publishing needs scoped permission and URL/readback evidence.
2. Flutter app: software pack with complete screen and state inventory, code/API/DB journey tests; precise SHA and separate release qualification.
3. Hourly news agent: publishing + automation, source attribution, scoped MCP permissions, durable schedule/retries, versioned approvals and corrections.
4. Compare cloud vendors: research, infrastructure when relevant, current pricing and cost scenarios; no resources provisioned for an analysis.
5. Brand graphic: design pack, actual image/editable source only as requested; no fake API deployment.
6. Spreadsheet dashboard: analytics, reproducible dataset and calculations, no fabricated inputs.
7. High-impact wallet: software + high assurance including approvals, security, reconciliation, rollback and real provider qualification.
8. Existing product change: inspect main/PRs/live source, preserve good behavior, complete vertical slice and safe merge then release separately.
