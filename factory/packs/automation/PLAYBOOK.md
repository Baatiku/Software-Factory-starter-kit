# AI agents and automation pack

Map trigger, inputs, output, tool inventory, credentials, user grants, permitted actions, policy, spend and stop controls. For scheduled tasks use durable execution, idempotency, concurrency claims, retries/backoff, deduplication, dead-letter/replay, receipts, timezones and failure alerts. MCP endpoints must enforce authorization independently of model text, use scoped expiring revocable keys and log actor/action/revision. For multi-agent design prefer a single capable operator with skills over excessive agents.

## Completion evidence
Demonstrated trigger→authorized tool→durable state→result/readback, negative permission tests, retry/idempotency tests and kill-switch controls; live provider tests distinguished.

Load only when this specialty is needed. The universal core controls permissions and evidence.
