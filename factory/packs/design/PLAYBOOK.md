# Design and creative production pack

Define audience, purpose, brand constraints, medium, accessibility and required editable assets. Research peer patterns, create a complete content/layout/component inventory, device variants, visual hierarchy, controls and interaction states when UI is involved. Respect licensing, attribution, rights and originality. Prefer native semantic controls and efficient assets rather than decorative complexity.

## Completion evidence
Actual requested medium, asset completeness, visual review, legibility/responsiveness/accessibility where applicable and source/editability only when requested.

Load only when this specialty is needed. The universal core controls permissions and evidence.
