# Project operator rules — Universal Work Factory
Read docs/WORK-OUTCOME.md, the local work-factory skill and the selected specialist skill before execution. Inspect current evidence, preserve existing work and follow the project's explicit decisions. Use only tools that are actually connected. Minimize documentation and vendor dependencies. For code, integrate compatible validated source and independently gate production; for research, design and publishing, use deliverable-appropriate evidence. Never claim a mock, scaffold, PR, draft or placeholder is a released outcome. Keep secrets private, scope agent tools and get authorization for destructive, paid, public or sensitive actions. Track the next concrete action and improve shared methods only after a reusable lesson is proven.
